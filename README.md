## 🚀 Sobre o projeto

Este projeto foi desenvolvido para realizar o cálculo do Índice de Massa Corporal (IMC) de forma simples e intuitiva. A aplicação permite que o usuário informe seu peso e altura e a partir desses dados, calcula e apresenta seu IMC. O projeto foi desenvolvido com o objetivo de praticar a criação de interfaces e a aplicação de lógica de programação com JavaScript.
